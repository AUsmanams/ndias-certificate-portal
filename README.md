# NDIAS 2026 Certificate Portal

Official certificate verification and download frontend for the NAZAS Digital Innovation & AI Summit (NDIAS) 2026.

Eligibility will include PRESENT attendance on approved training days, PRESENT attendance on graduation day (27 September 2026), approved EXCUSED status, or manual approval.

The public repository intentionally contains no participant database, phone numbers, emails, or eligibility registry. The verification endpoint will be connected separately.
